# Monika & Lukáš · 50 🌷

Romantic spring-inspired birthday invitation website.

## Files
- `index.html` — page content
- `styles.css` — complete responsive styling
- `script.js` — smooth scrolling and subtle petal movement

## Customize
Replace the photo placeholder, update the venue/address, RSVP email or URL, and replace the QR placeholder with the real QR code when ready.

No build step is required. Open `index.html` directly or use any static web server.
